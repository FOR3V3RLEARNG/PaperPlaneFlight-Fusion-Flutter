# Paper Plane Flight v2.2 — Pilot Character Roster

The race setup now includes a selectable pilot before AI Rival Race, Local Split Screen and Separate Device Race.

## Default playable characters
- YAALON — Wind Heart — distortion specialist.
- Uzziah — Sky Prince — slow-wind specialist.
- Nails — Hard Fold — fire-burst specialist.
- Wild Brats — Double Trouble — animated two-kid cockpit crew.
- Granny — Old School Ace — calm wind-reading specialist.
- George — Sky Monkey — original mischievous monkey pilot.
- Rose Panther — Velvet Velocity — original sleek pink-cat racer.

## Licensed character slot
`PINK PANTHER` is included only as a disabled integration slot. The exact Pink Panther character is not shipped as an original game asset and must remain locked unless the project has the necessary rights/license.

## Character animation language
Every playable pilot can react with focused, laughing, fist-pump, shocked, ducking, frustrated and celebrating states. The little rider sits directly on the paper plane and inherits the chosen character palette.

## Multiplayer
Local split screen lets both players select separate characters and Wing Levels 1–10. Rival Race selects both YAALON/player and AI rival characters. Separate-device lobby carries the selected character ID into the network setup.
